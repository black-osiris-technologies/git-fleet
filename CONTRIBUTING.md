# Contributing

Thanks for your interest in contributing.

This project is early, so the best contributions are small, focused changes with clear behavior and tests.

## Development

```text
go test ./...
go run ./cmd/omp-git-fleet scan --root .
```

## Pull Requests

- Keep changes scoped.
- Add or update tests when behavior changes.
- Avoid destructive Git operations unless they are guarded by explicit flags and tests.
